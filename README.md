Bem-vindo(a) à coleção de desafios para praticar Docker!  
Organizados em três níveis de dificuldade: **Fácil**, **Médio** e **Difícil**.  
Cada diretório contém exercícios práticos com instruções e dicas. 🚀

---

## 🧩 Níveis de Desafio

### 🟢 Fácil [`1.facil/`]
Desafios introdutórios para quem está começando com Docker:
- Rodando um container básico
- Criando e rodando um container interativo
- Listando e removendo containers
- Criando um Dockerfile para uma aplicação simples em Python

👉 Acesse: [`1.facil/`](/1.facil)

---

### 🟡 Médio [`2.medio/`]
Desafios para reforçar o conhecimento:
- Criando e utilizando volumes para persistência de dados
- Criando e rodando um container multi-stage
- Construindo uma rede Docker para comunicação entre containers
- Criando um compose file para rodar uma aplicação com banco de

👉 Acesse: [`2.medio/`](/2.medio)

---

### 🔴 Difícil [`3.dificil/`]
Desafios avançados para subir de nível:
- Criando uma imagem personalizada com um servidor web e arquivos estáticos
- Evitar execução como root
- Analisar imagem Docker com Trivy
- Corrigir vulnerabilidades encontradas

👉 Acesse: [`3.dificil/`](/3.dificil)
